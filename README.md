# 智核觉醒 · 完整说明

《智核觉醒》是一个本地演示项目，包含沉浸式登录入口、学员端、管理端和 Node.js 后端。项目按“5 个关卡 + 觉醒报告 + 6 个能力维度”组织：学员完成五关测评后生成觉醒报告；管理端维护班级、学员、题库、测评和数据看板。

## 当前版本口径

- 界面分为两个入口：**学员端**和**管理端**。
- 两个入口的账号空间相互独立，因此学员端和管理端都可以存在账号 `123456`。
- 登录进入哪个界面，不取决于账号本身，而取决于登录前选择的入口。
- 同一个入口内的账号不能重复；例如管理端不能再注册第二个 `123456`，但学员端和管理端可以各有一个 `123456`。
- 当前演示账号统一为：

| 入口 | 账号 | 密码 | 进入页面 |
|---|---|---|---|
| 学员端 | `123456` | `123456` | `/student.html`，再进入学员主页 |
| 管理端 | `123456` | `123456` | `/teacher.html`，进入管理后台 |

文件名里的 `student/` 和 `teacher/` 是历史目录名；界面和文档当前统一叫“学员端 / 管理端”。

## 快速启动

在 `AI-test` 目录，或仓库中包含 `backend/` 与 `frontend/` 的目录执行：

```powershell
node backend/src/server.js
```

启动后访问：

| 地址 | 用途 |
|---|---|
| <http://127.0.0.1:8787> | 首页与登录入口 |
| <http://127.0.0.1:8787/api> | 后端接口前缀 |
| <http://127.0.0.1:8787/api/health> | 健康检查 |

停止服务：在运行后端的终端按 `Ctrl + C`。

如果端口被占用，可以用另一个端口：

```powershell
$env:PORT="8788"; node backend/src/server.js
```

之后访问 `http://127.0.0.1:8788`。

## 登录规则和 401 处理

登录请求会携带 `scope`：

- `scope: "student"` 表示学员端；
- `scope: "admin"` 表示管理端。

后端先按账号和入口查找用户，再校验密码。因此：

- 学员端 `123456 / 123456` 进入学员端；
- 管理端 `123456 / 123456` 进入管理端；
- 如果在管理端入口输入学员端专属账号，即使密码正确，也不会进入学员界面。

如果出现“账号或密码不正确”，按下面顺序检查：

1. 确认后端正在运行，并确认浏览器访问的端口和后端端口一致。
2. 确认选择的入口正确：`123456` 在两个入口都有，但它们是两个不同账号。
3. 确认密码是 `123456`。
4. 如果之前手动修改过 `runtime.json`，或从旧数据切换到新种子数据，可能出现账号存在但缺少密码哈希字段的情况。当前代码会在后端加载时自动修复；修复代码更新后需要重启后端进程。
5. 不建议直接编辑 `runtime.json`。要恢复完整种子数据，先停止后端，再执行：

```powershell
$env:RESET_DB="1"; node backend/src/server.js
```

这会清空运行数据并重建演示账号、题库和空业务数据。确认数据恢复后，可以不带 `RESET_DB=1` 重新启动。

## 界面结构

### 登录入口

- `frontend/index.html` 是首页入口。
- `frontend/login/` 是 React/Vite 登录界面源码，构建产物输出到 `frontend/assets/`。
- 登录页包含品牌开场、身份选择、账号密码登录、注册、密码显隐和返回身份选择。

### 学员端

主要页面位于 `frontend/student/`：

| 页面 | 作用 |
|---|---|
| `main.html` | 学员首页、能力训练入口、分享论坛入口 |
| `level.html` | 能力训练 / 题目选择 |
| `fight.html` | 能力闯关答题流程和觉醒报告弹窗 |
| `sharing.html` | 分享论坛，支持浏览、发帖和评论 |
| `self.html` | 个人中心、觉醒报告历史、成长数据、错题集、账号与密码管理 |

学员端核心流程：

1. 登录学员端。
2. 从首页进入能力闯关或能力训练。
3. 后端按关卡、难度和已用题目抽题。
4. 每次提交答案都会记录到后端。
5. 五关完成后生成觉醒报告。
6. 报告保存到个人中心，可再次查看。
7. 闯关和训练中的错题会进入个人中心“错题集”。
8. 个人中心可修改当前入口内的账号/密码，也可退出登录。

### 管理端

主要逻辑位于 `frontend/teacher.html`、`frontend/teacher/teacher.js` 和 `frontend/teacher/teacher.css`。

管理端包含：

- 班级管理：创建、编辑、删除班级；
- 学员管理：按账号添加学员、选择班级、查看学员数据；
- 题库管理：查看、新增、导入、编辑、审核、删除题目；
- 测评管理：分为闯关和训练两类；
- 测评监控与结果；
- 学员画像与数据分析；
- CSV 导出和删除对应后端数据。

## 六维与五关

六个能力维度：

| 维度 | 说明 |
|---|---|
| AI 基础认知 | 理解 AI 的基本概念、能力和边界 |
| 提示词工程 | 清晰表达角色、任务、上下文、格式和验收标准 |
| AI 工具使用 | 选择和使用合适的 AI 工具完成任务 |
| AI 结果评估 | 判断 AI 输出的准确性、风险和可信度 |
| 人机协同 | 在 AI 辅助下保留人的判断与责任 |
| AI 伦理合规 | 处理隐私、偏见、安全和学术诚信问题 |

五个关卡：

1. 智核学院；
2. 信息迷城；
3. 创客工坊；
4. 协同空间站；
5. 伦理殿堂。

当前正式闯关为每关 5 题、共 25 题。题库文件 `backend/data/questions.json` 提供 120 道题，覆盖 6 个维度和低、中、高难度。

## 后端与数据

后端使用 Node.js 内置 HTTP 服务，没有第三方运行时依赖。入口是：

```text
backend/src/server.js
```

主要文件：

| 文件 | 作用 |
|---|---|
| `src/store.js` | JSON 数据读写和账号凭证迁移 |
| `src/security.js` | 密码哈希、Token 生成、内容安全检查 |
| `src/routes/auth.js` | 注册、登录、登出、当前用户 |
| `src/routes/student.js` | 学员资料、加入班级、报告历史、错题集 |
| `src/routes/quiz-session.js` | 学员端五关抽题、判分、练习记录、错题记录 |
| `src/routes/forum.js` | 论坛帖子、评论、浏览数、评论数 |
| `src/routes/teacher.js` | 管理端班级、学员、题库、测评、分析 |
| `src/routes/ai.js` | AI 生成、实操提交和评分 |
| `src/routes/assessment.js` | 旧版测评会话和防作弊记录 |

运行数据保存在：

```text
backend/data/runtime.json
```

种子数据保存在：

```text
backend/data/seed.json
```

学员端闯关当前优先读取 `backend/data/questions.json`；如果该文件不可用，会回退到 `runtime.json` 或 `seed.json` 里的题库。

## 常用命令

```powershell
# 正常启动
node backend/src/server.js

# 后端代码变化后自动重启
cd backend
npm run dev

# 接口冒烟测试
node backend/scripts/smoke.mjs

# 清空运行数据并重建种子
$env:RESET_DB="1"; node backend/src/server.js
```

修改登录界面的 React 源码后，构建登录产物：

```powershell
cd frontend/login
npm run build
```

如果依赖尚未安装，先执行：

```powershell
cd frontend/login
npm ci
```

## 环境变量

可以在 `backend/.env` 中配置：

| 变量 | 默认值 | 作用 |
|---|---|---|
| `PORT` | `8787` | 后端端口 |
| `HOST` | `127.0.0.1` | 监听地址 |
| `STATIC_ROOT` | `frontend` | 静态前端目录 |
| `TOKEN_TTL_HOURS` | `48` | 登录 Token 有效期 |
| `RESET_DB` | 空 | 设置为 `1` 时启动重建种子数据 |
| `BAIBAOXIAO_API_URL` | 空 | 外部 AI 服务地址 |
| `BAIBAOXIAO_API_TOKEN` | 空 | 外部 AI 服务 Token |

未配置外部 AI 服务时，AI 生成接口会返回本地演示内容，保证演示流程不断。

## 开发注意事项

- 不要直接修改 `runtime.json`；业务数据应通过接口或 `store.update()` 写入。
- 不要在数据库文件里保存明文密码；种子数据中的明文密码只用于首次启动时转换成哈希。
- 学员端和管理端账号按入口隔离，新增账号时必须带明确角色。
- 后端代码更新后需要重启进程；如果当前终端已经手动开启了后端，请由使用者自己重启，避免端口冲突或中断当前演示。
